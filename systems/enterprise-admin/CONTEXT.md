# enterprise-admin Context

## Domain language

- `tenant` means the isolated customer workspace.
- `POS` means the point-of-sale app in `pos-ui/`.
- `admin-ui` means the back-office web app in `admin-ui/`.
- `backend` means the API service in `backend/`.

## Important sources

- `ROADMAP.md` is the feature-progress source of truth.
- `ARCHITECTURE_HEALTH.md` captures the current technical debt and design notes.
- `infrastructure/adr/` contains architectural decisions that should be treated as constraints.

## Reading rule

Read the roadmap first when checking status. Read the ADRs before changing shared architecture or repo-wide conventions.
