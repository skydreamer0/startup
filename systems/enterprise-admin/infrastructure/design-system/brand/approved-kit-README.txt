使用
保持比例、留白、顏色與分界，不要拉伸或加陰影。SVG 畫布已留出邊界，不需緊貼圖形裁切。
一般介面優先使用 32 px 以上；16 px 為 favicon 用途，膠囊輪廓保留，中央細節會縮減。深背景使用 dark 或 white 版本。
預覽圖中的圓角只是應用示意，App icon 原檔為正方形。
