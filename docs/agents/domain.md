# Domain Docs

This repo uses a multi-context layout.

Read these files first when a skill asks for domain context:

- `CONTEXT-MAP.md` at the repo root
- `systems/enterprise-admin/CONTEXT.md`
- `docs/agents/navigation.md`
- `systems/enterprise-admin/infrastructure/adr/` when the task affects architecture

Use `docs/agents/navigation.md` to choose the smallest task-specific read set before opening source files.

If you are working in another system later, add its own `CONTEXT.md` and map it from `CONTEXT-MAP.md`.
