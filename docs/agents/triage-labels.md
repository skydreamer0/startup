# Triage Labels

The canonical triage roles map directly to the repo's GitHub label names:

| Role | Label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Use these exact strings unless the repo's label set changes.
