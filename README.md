# Startup Template Pack 使用說明（先看這份）

這個 repo 提供兩種內容：
1. **模板型文件**：幫你系統化整理商業與營運資料。
2. **落地執行文件**：幫你今天就開始做出第一筆營收。

如果你只有 30 分鐘，請先做這 3 件事：
- 先看 `startup_template_pack/27_30天創業落地執行版_非模板.md`
- 再看 `startup_template_pack/28_創業落地Roadmap_12週.md`
- 最後打開 `startup_template_pack/00_文件索引與填寫順序.md`，按順序補齊模板

---

## 你現在該從哪裡開始

### A. 你是「還沒有客戶」
1. 先執行 27 號文件第 1 週：訪談 + 開發 +試點報價。
2. 目標：7 天內拿到第一個願意試點的客戶。
3. 完成後再啟動 28 號文件 Week 3~4 的交付與複製銷售。

### B. 你是「有客戶但不穩定」
1. 先執行 28 號文件 Week 5~8，建立 SOP 與月費方案。
2. 補齊 `11_營運KPI與儀表板模板.md`、`12_單位經濟模型模板.md`。
3. 目標：把營收從單次案，轉成可預期 MRR。

### C. 你是「想擴張」
1. 先執行 28 號文件 Week 9~12（招人、治理、戰情會）。
2. 補齊 `21`~`25` 系列文件。
3. 目標：建立「不是你本人也能跑」的商業系統。

---

## 建議執行節奏（每週）

- 週一：訂本週 KPI（名單數、諮詢數、報價數、成交數）
- 週三：檢查漏斗（哪一段掉最多）
- 週五：戰情回顧 + 下週調整

建議你用同一份 Google Sheet 記錄：
- 名單來源
- 訪談重點
- 報價金額
- 成交/未成交原因
- 本週學到的 3 件事

---

## 交付成果（你應該看見的變化）

執行 12 週後，理想狀態：
- 有可複製的獲客流程
- 有標準化導入與驗收 SOP
- 有最少一條穩定的現金流產品（例如月費代營運）
- 有可直接給投資人或夥伴看的文件基礎
