These instructions supplement the repository-root `AGENTS.md` when reading or
maintaining files in `.agents/skills/`. They do not replace the repository's

## Pharmacy UI/UX skill route

Before applying `ui-ux-pro-max` to this repository, read
[PHARMACY-OVERRIDES.md](ui-ux-pro-max/PHARMACY-OVERRIDES.md), then the unchanged
[upstream SKILL.md](ui-ux-pro-max/SKILL.md). The pharmacy scope and local path
guide take precedence over generic upstream suggestions. Read only the relevant
reference or data file afterwards; do not load the entire catalogue into context.

The scripts are preserved as source material. This installation task does not
authorize running them. Persistence requires explicit authorization for its
destination and content; force overwrite requires separate confirmation.

See [README.md](README.md) for invocation and
[INSTALLATION.md](ui-ux-pro-max/INSTALLATION.md) for provenance and verification.
Keep upstream bytes unchanged and local rules in separate files.
