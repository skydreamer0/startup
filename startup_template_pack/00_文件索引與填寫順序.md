# 00_文件索引與填寫順序

## 用途
提供整套模板的填寫路徑、文件地圖與版本控管規則，確保團隊按正確順序完成材料。

## 適用時機
- 啟動模板包當天。
- 新成員加入時。
- 對外送件前總檢查時。

## 必填欄位
| 欄位       | 必填 | 說明                     |
| ---------- | ---- | ------------------------ |
| 文件名稱   | 是   | 檔名需與模板固定命名一致 |
| 文件負責人 | 是   | 主要填寫與維護者         |
| 版本號     | 是   | 例如 `v0.1`, `v1.0`      |
| 最後更新日 | 是   | `YYYY-MM-DD`             |
| 狀態       | 是   | `draft/review/approved`  |

## 填寫規則
1. 填寫順序固定：戰略 -> 合規 -> 營運 -> 財務 -> 對外文件。
2. 任何欄位命名需對齊 `20_主資料字典與欄位規範模板.md`。
3. 對外文件引用資料必須附上來源文件路徑。
4. 版本更新規則：重大結構調整升次版，內容補充升小版。

## 輸出範例格式
```text
[文件目錄與狀態]
01_創業論點與願景模板.md | owner: Founder | version: v0.3 | status: review
06_法規與合規矩陣_台灣模板.md | owner: Pharmacist Lead | version: v0.2 | status: draft
13_三年財務模型_月度模板.md | owner: Finance | version: v0.1 | status: draft

[填寫路徑]
Step1 戰略: 01 -> 02 -> 03 -> 04 -> 05
Step2 合規: 06 -> 07
Step3 營運: 08 -> 09 -> 10 -> 11
Step4 財務: 12 -> 13
Step5 對外: 14 -> 15 -> 19
Step6 執行計畫/風險: 16 -> 17 -> 18
Step7 人員/激勵/商業治理: 21 -> 22 -> 23 -> 24 -> 25
Step8 商業模型落地: 26 -> 11 -> 13 -> 25
```

## 常見錯誤
- 未先完成主資料字典就填其他模板。
- 對外文件引用未註明資料來源，導致審查追溯困難。
- 各文件版本不同步。

## 版本控管規則
1. 每次更新在文件底部增加 `Change Log`。
2. 每次送件前統一凍結版本，標記 `release_candidate`。
3. 禁止修改固定檔名，避免引用路徑失效。
4. 若口徑衝突，以 `20_主資料字典與欄位規範模板.md` 為準。
