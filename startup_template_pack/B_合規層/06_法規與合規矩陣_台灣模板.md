# 06_法規與合規矩陣_台灣模板

## 用途
盤點台灣法規與內部合規控制點，特別針對處方相關服務、藥事邊界、個資與文件留存建立可稽核矩陣。

## 適用時機
- 任何處方相關服務啟動前。
- 新流程上線前。
- 對外審查（投資/補助）前。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 法規主題 | string | 是 | 例如處方驗證、個資、廣告宣稱 |
| 適用條文/依據 | string | 是 | 法規來源 |
| 流程責任人 | string | 是 | 角色與簽核人 |
| 控制點 | text | 是 | 事前/事中/事後控制 |
| 證據文件 | string | 是 | SOP、紀錄單、系統留痕 |
| 稽核頻率 | string | 是 | 週/月/季 |
| 風險等級 | enum | 是 | low/medium/high/critical |
| `需藥師/法顧確認` | boolean | 是 | 任何結論必填 |

## 填寫規則
1. 本模板僅為管理工具，不構成法律意見。
2. 含處方流程的欄位必須有藥師責任人與簽核點。
3. 個資流程需定義蒐集目的、保存年限與刪除規則。
4. 每條合規要求須對應可查核證據檔案。

## 輸出範例格式
```text
[合規矩陣卡]
法規主題: <主題>
適用條文/依據: <來源>
流程責任人: <角色>
控制點: <內容>
證據文件: <文件名稱>
稽核頻率: <週/月/季>
風險等級: <low/medium/high/critical>
需藥師/法顧確認: true
```

## 常見錯誤
- 把合規責任寫給單一人員，未設定代理機制。
- 控制點沒有對應證據，無法稽核。
- 忽略個資刪除或更正流程。
