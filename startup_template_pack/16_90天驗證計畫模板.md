# 16_90天驗證計畫模板

## 用途
將商業假設拆成每週可執行任務與驗證門檻，快速判斷是否達到 Product-Market Fit 早期訊號。

## 適用時機
- 試點啟動前。
- 新客群/新通路上線前。
- 需要快速停損或轉向時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 假設 ID | string | 是 | 每個假設唯一編號 |
| 假設內容 | text | 是 | 可驗證敘述 |
| 驗證方法 | text | 是 | 訪談、A/B、實購 |
| 成功門檻 | string | 是 | 數字門檻 |
| 失敗門檻 | string | 是 | 停損條件 |
| 週任務 | list | 是 | 12 週任務拆解 |
| 責任人 | string | 是 | owner |
| Gate 決策 | string | 是 | go/pivot/stop |

## 填寫規則
1. 每週任務需對應至少一項假設。
2. 所有門檻以數字定義，不可只寫「改善」。
3. Week 4/8/12 必須安排 Gate Review。
4. 若觸發失敗門檻，需在 7 天內提出調整方案。

## 輸出範例格式
```text
[假設卡]
假設ID: HYP-001
假設內容: <內容>
驗證方法: <內容>
成功門檻: <數字>
失敗門檻: <數字>
責任人: <角色>

[週任務]
W1: <任務>
W2: <任務>
...
W12: <任務>

Gate決策: <go/pivot/stop>
```

## 常見錯誤
- 任務很多但沒有對應假設。
- 沒有停損門檻，導致無限試錯。
- Gate 會議沒有決策輸出。

### 初版12週排程（示例）
| 週次 | 目標 | 關鍵任務 | 指標 | 結果 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| W1 | 訪談與問綱定稿 | 完成10份訪談 | 有效樣本>=10 | 待填 | W2放大 |
| W2 | 首批SKU上架 | 上架20-30個SKU | 首購>=8 | 待填 | 優化動線 |
| W3 | LINE私域導流 | 到店導入LINE | 加入數>=60 | 待填 | 回購腳本 |
| W4 | Gate#1 | 檢視首購漏斗 | 首購>=18 | 待填 | go/pivot |
| W5-W8 | 回購機制測試 | 7/14/30天觸達 | 回購率>=20% | 待填 | Gate#2 |
| W9-W12 | 提升毛利與效率 | 組合包+促銷對照 | 毛利>=28% | 待填 | Gate#3 |

### 初版Gate規則（示例）
1. W4 Gate：首購不足門檻則縮減通路，聚焦高轉換點。
2. W8 Gate：回購不足門檻則重做商品組合與訊息節奏。
3. W12 Gate：若毛利與回購雙達標，進入第2階段擴張準備。
