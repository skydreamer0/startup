# 25_商業戰情會與績效結算模板

## 用途
建立週戰情、月結算、季制度調整的固定治理節奏，確保毛利、CCC、獎金發放與改善行動形成閉環。

## 適用時機
- 每週固定營運會議。
- 每月績效與獎金結算。
- 每季制度回顧與參數調整。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 會議編號 | string | 是 | 唯一識別碼 |
| 會議類型 | enum | 是 | weekly_war_room/monthly_settlement/quarterly_review |
| `period` | string | 是 | `YYYY-WW` 或 `YYYY-MM` |
| 核心指標摘要 | text | 是 | 毛利、CCC、缺貨、客訴、合規 |
| 決策事項 | list | 是 | 保留owner與截止日 |
| 風險升級項 | list | 是 | 需進入18號風險表 |
| 獎金結算結果 | text | 條件必填 | 月結算會議必填 |
| 制度調整結論 | text | 條件必填 | 季會議必填 |

## 填寫規則
1. 週會必看：`gross_margin_pct`、`ccc_days`、缺貨率、客訴率、合規事件數。
2. 月結會必算：`gate_pass` 與 `bonus_payout_twd`。
3. 季會必做：固定池級距、權重、門檻是否調整。
4. 每個決策項都需有 owner 與 due_date。

## 輸出範例格式
```text
[會議記錄]
meeting_id: WAR-2026-W18
meeting_type: weekly_war_room
period: 2026-W18
核心指標摘要: 毛利30.4%, CCC 9天, 缺貨率2.5%, 客訴率1.2%
決策事項:
- 調整B類SKU促銷策略 | owner: 採購 | due_date: 2026-05-12
- 低效社群素材下架 | owner: KOL負責人 | due_date: 2026-05-10
```

## 常見錯誤
- 會議只有回顧沒有決策與截止日。
- 月結算時未驗證雙門檻就先發獎金。
- 季度制度參數沒有依據就調整。
