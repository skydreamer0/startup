# 23_毛利提升作戰計畫模板

## 用途
建立毛利率提升的月度作戰機制，透過 SKU 結構、定價守門、採購議價與促銷控管，穩定達成 `gross_margin_pct >= 30`。

## 適用時機
- 毛利率低於目標時。
- 促銷檔期前後。
- 每月營運檢討與採購重談前。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `period` | string | 是 | `YYYY-MM` |
| `sku_tier` | enum | 是 | A/B/C |
| `revenue_share_pct` | number | 是 | 該層SKU營收占比 |
| `gross_margin_pct` | number | 是 | 該層毛利率 |
| `min_margin_pct` | number | 是 | 最低允許毛利率 |
| `discount_impact_twd` | number | 是 | 折扣影響毛利金額 |
| Top20議價進度_pct | number | 是 | 90天議價覆蓋率 |
| 低效SKU數 | number | 是 | 45天無動銷數 |

## 填寫規則
1. SKU 層級目標固定：A(40%/22-27%)、B(45%/32-38%)、C(15%/>=45%)。
2. 任何促銷需先跑毛利影響試算，未達標禁止上架。
3. Top20 SKU 每90天至少一次議價，目標平均成本下降3-5%。
4. 45天無動銷SKU必須進入清貨或下架流程。

## 輸出範例格式
```text
[毛利作戰主檔]
period: 2026-04
sku_tier: B
revenue_share_pct: 46
gross_margin_pct: 33.4
min_margin_pct: 30
discount_impact_twd: 4200
Top20議價進度_pct: 60
低效SKU數: 5
```

## 常見錯誤
- 促銷先上線再看毛利，導致不可逆損失。
- 只看總毛利，忽略各SKU層級結構惡化。
- 議價未制度化，成本遞增未被控制。

## 初版填寫示例（可直接改）
```text
[毛利作戰主檔]
period: 2026-05
A層: revenue_share_pct=42, gross_margin_pct=25.3
B層: revenue_share_pct=44, gross_margin_pct=33.1
C層: revenue_share_pct=14, gross_margin_pct=45.8
整體毛利率_pct: 30.2
Top20議價進度_pct: 70
低效SKU數: 4

[本月行動]
1) 下架2個低效SKU
2) A層引流品促銷改為組合包，避免單品毛利跌破22%
3) 完成Top20 SKU第2輪議價，目標成本再降2%
```
