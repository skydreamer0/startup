# 15_補助申請模板_台灣新創中小企業

## 用途
對齊台灣新創/中小企業補助常見評分面向，快速組裝可審查的申請文本。

## 適用時機
- 補助公告確認後。
- 申請書撰寫與內部審查階段。
- 送件前最終核對。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 計畫名稱 | string | 是 | 與申請主題一致 |
| 計畫目標 | text | 是 | 可量化成果 |
| 創新性說明 | text | 是 | 技術/模式/流程創新 |
| 可行性說明 | text | 是 | 團隊、資源、時程 |
| 預期效益 | text | 是 | 產值、就業、社會影響 |
| 執行里程碑 | list | 是 | 月/季節點 |
| 預算明細_twd | table | 是 | 經費用途與比例 |
| 風險與因應 | text | 是 | 風險管控 |
| 佐證文件索引 | list | 是 | 對應 `19` 文件 |

## 填寫規則
1. 每個目標需對應可量測 KPI。
2. 預算欄位與 `13` 財務模型一致。
3. 創新性需對照現有替代方案差異。
4. 所有數據必須附來源或可追溯依據。

## 常見錯誤
- 只寫願景，缺少可驗證產出。
- 預算項目無法對應實際執行。
- 佐證文件未整理，審查追查困難。

## 補助送件初稿（段落文案版，可直接貼申請系統）

### 一、計畫名稱
越南族群導向社群藥局服務與商品供應創新計畫

### 二、計畫摘要（送件版）
本計畫聚焦新北市下新莊越南族群，建立「實體藥局據點 + 越語社群 + LINE 私域」的一站式商品與服務模式，解決目標族群在健康與生活商品取得上的資訊落差、信任缺口與供應不穩問題。相較一般泛大眾通路，本計畫以語言友善、社群信任與流程可稽核為核心，優先服務高頻需求場景，並以 90 天驗證機制建立可重複首購與回購漏斗。計畫執行期間為 2026 年 4 月 1 日至 2027 年 3 月 31 日，預計完成單點可複製營運模型、資料化 KPI 管理機制、合規流程標準化與第二收入引擎驗證。整體目標為在低預算條件下驗證利基族群可持續商業模式，形成可複製之在地社群實業範本，提升族群服務可近性與中小企業創新競爭力。

### 三、計畫背景與問題說明
本案觀察到越南族群在在地生活中，雖可透過一般通路或非正式代購取得部分商品，但常面臨三項核心問題。第一，商品與資訊來源分散，缺乏穩定且可信任的選購與使用支持。第二，語言與文化差異造成決策成本升高，尤其在健康相關需求中更易產生錯誤判斷。第三，既有通路多以泛大眾設計，未能形成針對利基族群的長期回購與服務關係。  
本計畫以「先深耕單點、再複製擴張」為原則，避免早期過度擴張造成資源分散，先在下新莊建立完整可運作流程，包含商品策略、社群內容、私域回購、營運數據、風險控管與合規稽核，再進一步評估跨區複製可行性。

### 四、計畫目標與量化KPI
本計畫設定以下可驗證目標：  
1. 90 天完成 50-100 位有效付費顧客，驗證首購漏斗可重複性。  
2. 30 日回購率達 25% 以上，確認私域經營與服務機制有效。  
3. 月毛利率達 28% 以上，建立可持續營運基礎。  
4. 建立合規矩陣與 SOP，處方相關流程可稽核、可追溯（需藥師/法顧確認）。  
5. 建立週/月 KPI 儀表板與月度財務模型，形成決策閉環。  
上述指標將以 `11_營運KPI與儀表板模板.md`、`12_單位經濟模型模板.md`、`13_三年財務模型_月度模板.md` 為追蹤依據，每月固定檢討並輸出修正計畫。

### 五、創新性說明
本計畫之創新性主要體現在「模式整合創新」與「流程治理創新」兩個層面。模式整合上，本案將實體藥局信任基礎、越語社群觸達能力與 LINE 私域回購能力整合為單一營運引擎，使獲客與留存不再分離。流程治理上，本案導入標準化資料欄位、風險登錄、合規稽核與月度財務滾動管理，將早期創業從經驗驅動提升為數據驅動，降低試錯成本並提高可複製性。  
此外，本案在同等預算下，以利基族群高密度單點經營取代廣域投放，預期可在更短時間內形成可驗證的單位經濟與社群黏著，對台灣中小企業在地化創新與精準服務模式具示範價值。

### 六、執行方法與工作項目
本計畫採四階段推進。第一階段（M1-M2）完成需求驗證、首批 SKU 上架、合規流程定版；第二階段（M3-M4）放大首購與私域名單，完成 90 天 Gate 驗證；第三階段（M5-M8）優化回購與毛利結構，建立穩定供應與內容節奏；第四階段（M9-M12）啟動第二收入引擎驗證（B2B 團購、社群共銷），產出可複製條件清單。  
各工作項目將以周任務管理與月度里程碑驗收執行，確保任務、預算、指標三者一致，並透過文件化機制保留可審查紀錄。

### 七、執行時程與里程碑（送件版）
| 期間 | 里程碑主題 | 主要交付成果 | 驗收指標 |
| --- | --- | --- | --- |
| 2026Q2 | 啟動與驗證 | 訪談完成、首批SKU上架、SOP上線 | 有效訪談>=30、首購>=35 |
| 2026Q3 | 漏斗放大 | LINE私域名單成長、回購機制落地 | 有效顧客50-100、30日回購>=25% |

### 八、團隊組成與角色分工
本計畫由創辦人擔任計畫主持，負責整體策略、資源整合與關鍵決策。營運與通路執行由兼職越語夥伴協作，負責社群觸達、私域運營與客戶溝通。供應與商品管理由採購角色負責 SKU 結構、補貨節奏與供應商管理。處方相關流程由合作藥師依專業分工執行簽核與稽核（需藥師/法顧確認）。  
本團隊配置採「低固定成本 + 高執行密度」原則，確保補助資源可直接轉換為驗證成果，並保有快速調整能力。

### 九、經費編列與合理性說明（TWD）
本計畫總預算為新台幣 3,000,000 元，配置如下：人事 900,000 元（30%）、行銷通路 750,000 元（25%）、庫存與供應 900,000 元（30%）、合規與法務 250,000 元（8.3%）、管理與預備金 200,000 元（6.7%）。  
上述配置與計畫目標直接對應：庫存與供應確保履約穩定；行銷通路支撐首購與回購漏斗；人事確保營運落地與社群服務品質；合規法務用於流程稽核與風險降低；預備金用於異常情境應對。預算口徑與月度財務模型一致，並採月度滾動檢討機制。

### 十、預期效益（經濟、社會、產業）
經濟效益方面，預期於 6 個月內達成月營運現金流接近損平，並在 12 個月內形成可持續營運結構。社會效益方面，透過語言友善與可追溯服務流程，提升越南族群在健康與生活商品取得上的可近性與資訊透明度。產業效益方面，本案提供一套可被複製的「利基族群社群實業」方法論，作為中小企業進行在地化創新與精準服務之示範案例。  
此外，本計畫建立的資料化管理與風險治理機制，可提升後續外部合作、融資與擴點的可信度。

### 十一、風險評估與因應機制
本案主要風險包含合規風險、供應風險、獲客成本風險與聲譽風險。合規風險以「合規矩陣 + SOP + 簽核留痕」控管，重大事件採 24-72 小時關閉機制（需藥師/法顧確認）。供應風險以 A 級 SKU 安全庫存與備援供應商策略降低斷貨機率。獲客成本風險透過通路分層與素材迭代機制管理，若 CAC 連續超標則啟動停損與資源重配。聲譽風險則以內容審稿、客訴 SLA 與事件通報制度管控。  
風險控管將以 `18_風險登錄與應對模板.md` 每週更新，確保問題可被提早識別與處理。
