# 12_單位經濟模型模板

## 用途
量化每位客戶與每筆交易是否可持續獲利，連結營運數據與財務預測。

## 適用時機
- 試點第 1 個月起每月更新。
- 定價調整前後。
- 募資/補助說明商業可行性時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `period` | string | 是 | `YYYY-MM` |
| `cac_twd` | number | 是 | 平均獲客成本 |
| 客單價_twd | number | 是 | AOV |
| `gross_margin_pct` | number | 是 | 毛利率 |
| 購買頻次_月 | number | 是 | 每月購買次數 |
| 留存月數 | number | 是 | 平均持續月份 |
| LTV_twd | number | 是 | 生命週期價值 |
| 回本月數 | number | 是 | CAC 回收時間 |
| `assumption_id` | string | 是 | 對應 `FinancialAssumptionV1` |

## 填寫規則
1. 幣別固定 TWD，期間固定月度。
2. 所有公式以文字描述且固定口徑。
3. 需提供 low/base/high 三情境。
4. 任何假設變動需記錄來源與生效月。

## 輸出範例格式
```text
[單位經濟]
period: YYYY-MM
cac_twd: <數字>
客單價_twd: <數字>
gross_margin_pct: <數字>
購買頻次_月: <數字>
留存月數: <數字>
LTV_twd: <數字>
回本月數: <數字>

[公式說明]
LTV_twd = 客單價_twd * 毛利率 * 購買頻次_月 * 留存月數
回本月數 = cac_twd / (客單價_twd * 毛利率 * 購買頻次_月)
```

## 常見錯誤
- LTV 與毛利口徑混淆（用營收代替毛利）。
- 把短期活動效果當作長期常態。
- 沒有情境分析，過度樂觀。

## 初版填寫示例（可直接改）
```text
[單位經濟-base]
period: 2026-03
cac_twd: 172
客單價_twd: 655
gross_margin_pct: 28.6
購買頻次_月: 1.4
留存月數: 6
LTV_twd: 1573
回本月數: 0.66
assumption_id: ASM-UE-001

[公式說明]
LTV_twd = 客單價_twd * (gross_margin_pct/100) * 購買頻次_月 * 留存月數
回本月數 = cac_twd / (客單價_twd * (gross_margin_pct/100) * 購買頻次_月)
```

### 初版情境分析（示例）
| 指標 | Low | Base | High | 說明 |
| --- | --- | --- | --- | --- |
| cac_twd | 220 | 172 | 130 | 通路效率差異 |
| 客單價_twd | 580 | 655 | 760 | 組合包比重差異 |
| 毛利率_pct | 24.0 | 28.6 | 33.0 | SKU 結構差異 |
| 留存月數 | 4 | 6 | 9 | 回購機制成熟度差異 |

### 初版決策門檻（示例）
1. `回本月數 > 2.0`：立即凍結高CAC通路並調整素材。
2. `LTV_twd / cac_twd < 2.5`：優先調整商品組合與回購節奏。
3. `gross_margin_pct < 24`：啟動第二收入方案評估。
