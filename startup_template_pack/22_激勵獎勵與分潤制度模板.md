# 22_激勵獎勵與分潤制度模板

## 用途
建立可計算、可稽核、可調整的激勵制度，將個人績效與毛利/現金循環目標綁定，避免只衝營收造成虧損。

## 適用時機
- 每月績效結算時。
- 每季制度調整時。
- 發生獎金爭議或需要對外審查時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `incentive_plan_id` | string | 是 | 對應 `IncentivePlanV1` |
| `period` | string | 是 | `YYYY-MM` |
| `fixed_pool_twd` | number | 是 | 固定獎金池 |
| `extra_pool_twd` | number | 是 | 超額毛利獎金池 |
| `gross_margin_pct` | number | 是 | 當月毛利率 |
| `ccc_days` | number | 是 | 當月現金轉換週期 |
| `gate_pass` | boolean | 是 | 是否通過雙門檻 |
| `score_weight_business` | number | 是 | 商業權重 |
| `score_weight_service` | number | 是 | 服務權重 |
| `score_weight_compliance` | number | 是 | 合規權重 |
| `major_compliance_incident_count` | number | 是 | 重大合規事件數 |

## 填寫規則
1. 發放雙門檻固定：`gross_margin_pct >= 30` 且 `ccc_days <= 30`。
2. 若 `major_compliance_incident_count > 0`，當月變動獎金歸零。
3. 權重預設：商業60/服務20/合規20，總和必須等於100。
4. 採月結、季調整；連續3個月達標可上調固定池10%。

## 輸出範例格式
```text
[激勵計畫主檔]
incentive_plan_id: INC-202604
period: 2026-04
fixed_pool_twd: 12000
extra_pool_twd: 3500
gross_margin_pct: 31.2
ccc_days: 27
major_compliance_incident_count: 0
gate_pass: true
score_weight_business: 60
score_weight_service: 20
score_weight_compliance: 20
```

## 常見錯誤
- 用營收當獎金基礎，忽略毛利與現金風險。
- 權重設定後未定期回顧。
- 未設凍結條件，導致重大違規仍可領獎。

---

## 獎金公式模板
```text
固定獎金池(預設): fixed_pool_twd = 12000
超額毛利獎金: extra_pool_twd = MIN(MAX(0, 當月毛利_twd - 毛利目標_twd) * 10%, 8000)
可發放獎金池: payout_pool_twd = IF(AND(gross_margin_pct >= 30, ccc_days <= 30, major_compliance_incident_count = 0), fixed_pool_twd + extra_pool_twd, 0)
個人獎金: payout_twd = payout_pool_twd * score_share_pct
```
