# 31_每週戰情會議程與紀錄模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder / Ops |
| Update Frequency | 每週五固定更新 |
| Input From | 11_營運KPI、12_單位經濟、18_風險登錄、25_戰情會制度 |
| Output To | 下週優先級清單、跨角色行動項、風險升級項 |

## 用途
將每週戰情會標準化，確保會議有固定節奏、可追蹤決策與明確 owner，不讓會議停留在「報告進度」。

## 適用時機
- 每週固定戰情會（建議週五）。
- 重大異常（毛利驟降、缺貨、客訴暴增）臨時加開會議。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| meeting_id | string | 是 | 例：WAR-2026-W21 |
| period | string | 是 | 例：2026-W21 |
| 主持人 | string | 是 | Founder 或 Ops |
| 與會角色 | list | 是 | Founder/Ops/Finance/BD |
| 本週核心指標摘要 | text | 是 | 至少含到店、首購、回購、毛利、現金流 |
| Top 3 問題 | list | 是 | 本週最影響成長的 3 件事 |
| 決策清單 | list | 是 | 每項需有 owner + due_date |
| 升級風險 | list | 否 | 需同步至 18_風險登錄 |

## 會議流程（45 分鐘）
1. **5 分鐘**：上週行動項完成率回顧。
2. **10 分鐘**：核心指標快照（只看異常與趨勢）。
3. **15 分鐘**：Top 3 問題深挖（根因與影響）。
4. **10 分鐘**：做決策（保留 owner、截止日、驗收標準）。
5. **5 分鐘**：確認下週唯一優先級與風險升級項。

## 常見錯誤
- 只有指標報告，沒有決策與截止日。
- 一次列太多優先級，導致下週失焦。
- 風險只討論不落盤，未同步到 `18_風險登錄與應對模板.md`。
