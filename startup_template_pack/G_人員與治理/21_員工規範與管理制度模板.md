# 21_員工規範與管理制度模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder / HR Ops |
| Update Frequency | 每月更新；制度異動與招募期加更 |
| Input From | C_營運節奏、D_績效數據、F_驗證節點 |
| Output To | 全體執行規範、績效結算、跨角色協作節奏 |


## 用途
建立創辦人與兼職團隊可執行的基礎管理制度，統一出勤、交接、服務品質、合規與懲處規則。

## 適用時機
- 團隊啟動或新增兼職成員時。
- 服務品質波動、客訴上升時。
- 對外審查需提供人員治理制度時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `policy_id` | string | 是 | 對應 `EmployeePolicyV1.policy_id` |
| `role_type` | enum | 是 | founder/part_time_ops/part_time_kol/part_time_procurement |
| 出勤規範 | text | 是 | 排班、遲到、請假規則 |
| 交接規範 | text | 是 | 班前、班後交接清單 |
| 保密規範 | text | 是 | 顧客/交易/流程資料保密 |
| 服務規範 | text | 是 | 溝通語氣、回覆時效、客訴SLA |
| 宣稱禁限規範 | text | 是 | 禁用內容與審稿流程 |
| 懲處矩陣 | table | 是 | reminder/warning/major_violation |
| `compliance_required` | boolean | 是 | 合規簽核必要性 |

## 填寫規則
1. 所有角色都需對應 `role_type`，不可省略。
2. 出勤與交接規範需可量測（例如分鐘、時限、表單完成率）。
3. 宣稱與處方相關內容必須標註「需藥師/法顧確認」。
4. 懲處矩陣需對應具體事件與處理時限。

## 輸出範例格式
```text
[員工規範主檔]
policy_id: POL-OPS-001
role_type: part_time_ops
出勤規範: 排班前24小時確認；遲到10分鐘內需回報
交接規範: 每班交接清單完成率需100%
保密規範: 顧客資料不得外傳
服務規範: 私訊24小時內回覆；客訴48小時內初步處置
宣稱禁限規範: 禁止療效保證字眼（需藥師/法顧確認）
compliance_required: true
```

## 常見錯誤
- 只寫原則沒有可稽核標準。
- 兼職人員缺乏交接制度導致品質不一致。
- 合規違規與懲處條件未綁定。

## 交接清單模板
- 班前：待處理訂單、缺貨項、客訴件、合規待簽核項
- 班中：異常事件即時紀錄、回覆時效追蹤
- 班後：交接紀錄上傳、未結案項目標記owner

## 懲處矩陣模板
| discipline_level | 觸發條件 | 處置方式 | 處理時限 |
| --- | --- | --- | --- |
| reminder | 輕微程序違反 | 書面提醒 + 再訓練 | 48 小時 |
| warning | 重複違反或影響服務品質 | 當月績效扣分 + 書面警告 | 24 小時 |
| major_violation | 重大合規或資料外洩 | 當月變動獎金歸零 + 升級處理 | 24 小時 |

## 初版填寫示例（可直接改）
```text
[員工規範主檔]
policy_id: POL-OPS-001
role_type: part_time_ops
出勤規範: 排班前24小時確認；遲到超過10分鐘記錄一次
交接規範: 每班交接清單100%完成，未完成不得下班
保密規範: 顧客聯絡資料與訂單資料僅限內部系統使用
服務規範: 顧客訊息24小時內回覆；客訴48小時內提出處置方案
宣稱禁限規範: 禁止療效保證、誇大用語（需藥師/法顧確認）
compliance_required: true

[懲處執行]
- 輕微違規: 第1次書面提醒
- 再犯: 當月績效扣5分
- 重大合規違規: 當月變動獎金歸零
```
