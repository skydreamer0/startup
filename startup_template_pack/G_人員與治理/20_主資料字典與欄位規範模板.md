# 20_主資料字典與欄位規範模板

## 用途
統一定義全文件共用欄位、資料型別、ID 規則與口徑，避免各模板命名不一致，確保市場、營運、財務與對外文件可以互相對接。

## 適用時機
- 建立整套模板前先完成本文件。
- 任何模板新增欄位前先更新本文件。
- 對外送件（募資/補助）前用於口徑檢核。

## 必填欄位
| 類別 | 欄位/型別名稱 | 必填 | 說明 |
| --- | --- | --- | --- |
| 主檔 | `startup_id` | 是 | 創業主體唯一代碼 |
| 主檔 | `company_name` | 是 | 公司/品牌名稱 |
| 主檔 | `pilot_region` | 是 | 試點區域 |
| 主檔 | `stage` | 是 | `idea/mvp/traction` |
| 主檔 | `budget_range_twd` | 是 | 預算區間描述 |
| 共用 | `period` | 是 | `YYYY-MM` 或 `YYYY-WW` |
| 共用 | `source_note` | 是 | 資料來源與備註 |

## 填寫規則
1. 幣別一律使用 `TWD`。
2. 月度資料採 `YYYY-MM`，週資料採 `YYYY-WW`。
3. 百分比欄位一律使用數值（例如 `28.5` 表示 28.5%）。
4. 金額欄位以稅前新台幣表示，不加千分位符號。
5. 布林欄位只能填 `true` 或 `false`。
6. 枚舉欄位只能使用本文件定義值。
7. 若欄位空值，需加上 `reason_for_null`（原因說明）。
8. 任何法規相關結論欄位必須標記：`需藥師/法顧確認`。

## 輸出範例格式
```text
[主資料字典版本]
dictionary_version: V1.0
updated_at: YYYY-MM-DD
owner: <姓名/角色>

[欄位口徑]
currency: TWD
time_granularity_finance: monthly
time_granularity_ops: weekly_and_monthly

[枚舉]
stage: idea | mvp | traction
channel_id: store | line | community | kol
verification_status: pending | verified | rejected | escalated
```

## 常見錯誤
- 同一欄位在不同文件使用不同命名（例如 `gross_margin` 與 `gross_margin_pct` 混用）。
- 週/月時間格式混用導致 KPI 無法聚合。
- 金額同時出現含稅與未稅口徑。
- 合規結論未標示 `需藥師/法顧確認`。

## ID 規則
| 物件 | 格式 | 範例 |
| --- | --- | --- |
| startup_id | `STP-YYYY-XXX` | `STP-2026-001` |
| segment_id | `SEG-XXX` | `SEG-VNM-001` |
| sku_id | `SKU-XXX` | `SKU-HLT-015` |
| rx_case_id | `RX-YYYYMM-XXXX` | `RX-202602-0001` |
| partner_id | `PTN-XXX` | `PTN-COM-002` |
| assumption_id | `ASM-XXX` | `ASM-REV-003` |
| policy_id | `POL-XXX` | `POL-OPS-001` |
| employee_id | `EMP-XXX` | `EMP-PT-003` |
| incentive_plan_id | `INC-YYYYMM` | `INC-202604` |

## 共用欄位命名規範
- 請使用 `snake_case`。
- 百分比欄位一律以 `_pct` 結尾。
- 新台幣欄位一律以 `_twd` 結尾。
- 日期時間欄位：日期用 `_date`，時間戳用 `_timestamp`。

## 枚舉值字典
```text
stage = idea | mvp | traction
channel_id = store | line | community | kol
verification_status = pending | verified | rejected | escalated
service_type = product_only | rx_related | bundle
risk_level = low | medium | high | critical
role_type = founder | part_time_ops | part_time_kol | part_time_procurement
discipline_level = reminder | warning | major_violation
```

## 重要介面與資料型別

### StartupProfileV1
```text
- startup_id (string)
- company_name (string)
- pilot_region (string)
- target_segments (string[])
- stage (enum: idea/mvp/traction)
- budget_range_twd (string)
```

### SegmentProfileV1
```text
- segment_id (string)
- segment_name (string)
- problem_statement (string)
- urgency_score (1-5)
- willingness_to_pay (1-5)
```

### SKUProfileV1
```text
- sku_id (string)
- sku_name (string)
- category (enum)
- unit_cost_twd (number)
- unit_price_twd (number)
- gross_margin_pct (number)
- compliance_flag (boolean)
```

### RxServiceRecordV1
```text
- rx_case_id (string)
- verification_status (enum)
- pharmacist_signoff (string)
- handoff_timestamp (datetime)
- incident_flag (boolean)
```

### ChannelKPIRecordV1
```text
- period (YYYY-MM or YYYY-WW)
- channel_id (store/line/community/kol)
- new_customers (number)
- repeat_customers (number)
- conversion_rate_pct (number)
- cac_twd (number)
```

### FinancialAssumptionV1
```text
- assumption_id (string)
- assumption_name (string)
- base_value (number)
- low_case (number)
- high_case (number)
- source_note (string)
```

### EmployeePolicyV1
```text
- policy_id (string)
- role_type (enum: founder/part_time_ops/part_time_kol/part_time_procurement)
- attendance_rule (string)
- discipline_level (enum: reminder/warning/major_violation)
- compliance_required (boolean)
```

### IncentivePlanV1
```text
- incentive_plan_id (string)
- period (YYYY-MM)
- fixed_pool_twd (number)
- extra_pool_twd (number)
- gross_margin_pct (number)
- ccc_days (number)
- gate_pass (boolean)
- score_weight_business (number)
- score_weight_service (number)
- score_weight_compliance (number)
```

### IncentivePayoutLedgerV1
```text
- employee_id (string)
- period (YYYY-MM)
- score_total (number)
- score_share_pct (number)
- payout_twd (number)
- freeze_reason (string)
```

### MarginOpsRecordV1
```text
- period (YYYY-MM)
- sku_tier (enum: A/B/C)
- revenue_share_pct (number)
- gross_margin_pct (number)
- discount_impact_twd (number)
```

### CashCycleRecordV1
```text
- period (YYYY-MM)
- dio_days (number)
- dso_days (number)
- dpo_days (number)
- ccc_days (number)
- cash_alert_flag (boolean)
```

## 跨文件引用清單
- 戰略文件（01-05）至少引用：`StartupProfileV1`、`SegmentProfileV1`。
- 合規文件（06-07）至少引用：`RxServiceRecordV1`。
- 營運文件（08-11、16-18）至少引用：`SKUProfileV1`、`ChannelKPIRecordV1`。
- 財務文件（12-13）至少引用：`FinancialAssumptionV1`、`SKUProfileV1`。
- 對外文件（14-15、19）需引用上述型別做證據索引。
- 人事制度文件（21）至少引用：`EmployeePolicyV1`。
- 激勵制度文件（22、25）至少引用：`IncentivePlanV1`、`IncentivePayoutLedgerV1`。
- 毛利與現金循環文件（23、24）至少引用：`MarginOpsRecordV1`、`CashCycleRecordV1`。

### 初版欄位治理規則（示例）
1. 新增欄位前先更新本檔並指定 owner。
2. 任何文件引用欄位若改名，必須同步更新所有引用檔。
3. 對外送件前執行一次欄位一致性檢查（命名、型別、期間、幣別）。
