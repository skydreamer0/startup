# 05_商業模式與定價模板

## 用途
定義收入來源、成本結構、毛利目標與定價實驗設計，作為單位經濟與財務模型的上游文件。

## 適用時機
- 試點上線前。
- 毛利波動超過警戒值時。
- 新收入來源導入前。

## 必填欄位
| 欄位               | 型別   | 必填 | 說明                     |
| ------------------ | ------ | ---- | ------------------------ |
| 收入來源清單       | list   | 是   | 商品、服務、合作分潤等   |
| 定價策略           | text   | 是   | 成本加成/價值定價/組合包 |
| `unit_cost_twd`    | number | 是   | 來自 `SKUProfileV1`      |
| `unit_price_twd`   | number | 是   | 來自 `SKUProfileV1`      |
| `gross_margin_pct` | number | 是   | 單品或組合毛利           |
| 折扣規則           | text   | 是   | 促銷條件與期間           |
| 第二收入假設       | text   | 是   | B2B 團購/KOL 共銷等      |

## 填寫規則
1. 每個收入來源需標記佔比目標與驗證週期。
2. 定價需有 A/B 測試設計與停損條件。
3. 毛利計算口徑要和 `12`、`13` 文件一致。
4. 第二收入來源需標記啟動條件（如毛利低於門檻）。

## 輸出範例格式
```text
[收入來源]
1) 商品單次交易
2) 處方相關服務附加價值
3) B2B 團購合作

[定價卡]
sku_id: SKU-XXX
unit_cost_twd: <數字>
unit_price_twd: <數字>
gross_margin_pct: <數字>
折扣規則: <內容>

[第二收入啟動條件]
觸發條件: <例如毛利<20%連續2月>
啟動方案: <方案內容>
```

## 常見錯誤
- 只看營收，不看毛利與現金流速度。
- 促銷過度侵蝕毛利。
- 第二收入沒有明確觸發條件。

## 初版填寫示例（可直接改）
```text
[收入來源]
1) 商品單次交易（主收入）
2) 處方相關服務附加價值（需藥師/法顧確認）
3) B2B 團購合作（第二收入）
4) 社群共銷與品牌合作檔期收入（第二收入）

[收入占比目標]
M1-M3: 商品85% / 服務10% / 其他5%
M4-M6: 商品70% / 服務15% / 其他15%

[SKU定價卡A]
sku_id: SKU-HLT-001
unit_cost_twd: 180
unit_price_twd: 280
gross_margin_pct: 35.7
折扣規則: 首購95折，回購滿1200折80

[SKU定價卡B]
sku_id: SKU-LIV-003
unit_cost_twd: 95
unit_price_twd: 160
gross_margin_pct: 40.6
折扣規則: 組合包第二件9折

[定價策略]
- 高頻剛需品採中低毛利拉高周轉
- 長尾補充品採中高毛利提升結構毛利
- 以組合包提升客單價與回購率

[第二收入啟動條件]
觸發條件: 連續2個月毛利率<20% 或 CAC_twd > 首購毛利
啟動方案:
1) 推出企業/宿舍團購方案（固定補給包）
2) 啟動越南社群KOL共銷合作（固定分潤）
3) 導入供應商檔期合作費
```

### 初版商業模式畫布（示例）
- 客群：下新莊越南族群（移工、新住民、家庭照護者）
- 價值主張：可信任、可近性高、語言友善的商品與服務
- 通路：實體店、LINE 私域、社群節點
- 客戶關係：越語客服、回購提醒、社群活動
- 收入來源：單次交易為主，B2B/KOL 共銷為輔
- 關鍵資源：供應鏈、藥師合作、社群夥伴
- 關鍵活動：SKU管理、社群內容、回購運營
- 關鍵夥伴：供應商、越南社群節點、合作藥師
- 成本結構：進貨成本、人力、通路與社群營運、合規成本
