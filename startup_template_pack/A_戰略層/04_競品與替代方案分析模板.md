# 04_競品與替代方案分析模板

## 用途
分析直接競品、間接競品與非正式替代方案，找出差異化與進入障礙。

## 適用時機
- 商業模式定稿前。
- 通路策略調整前。
- 募資與補助說明競爭優勢時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 競品名稱 | string | 是 | 直接/間接皆可 |
| 類型 | enum | 是 | direct/indirect/substitute |
| 目標客群 | string | 是 | 競品主要客群 |
| 價格區間_twd | string | 是 | 估計或公開價格 |
| 優勢 | text | 是 | 競品強項 |
| 劣勢 | text | 是 | 競品限制 |
| 我方差異化 | text | 是 | 可被驗證的不同點 |
| 進入障礙 | text | 是 | 法規、供應、品牌、通路 |

## 填寫規則
1. 每個類型至少列 3 個對象。
2. 差異化需對應到可量化指標（速度、價格、回購率等）。
3. 每季更新一次。
4. 避免只用主觀評語，需有證據來源。

## 輸出範例格式
```text
[競品卡]
競品名稱: <名稱>
類型: <direct/indirect/substitute>
目標客群: <描述>
價格區間_twd: <區間>
優勢: <內容>
劣勢: <內容>
我方差異化: <內容>
進入障礙: <內容>
source_note: <資料來源>
```

## 常見錯誤
- 只比較功能，不比較履約能力與信任成本。
- 忽略「不用任何產品」也是替代方案。
- 差異化無法轉成銷售話術或營運能力。

## 初版填寫示例（可直接改）
```text
[競品卡A]
競品名稱: 一般連鎖藥妝/藥局
類型: direct
目標客群: 一般大眾
價格區間_twd: 中
優勢: 品牌知名、商品齊全
劣勢: 越語服務與社群信任鏈不足
我方差異化: 越南族群聚焦、社群與LINE私域深度經營
進入障礙: 我方需快速建立穩定供應與服務標準
source_note: 實地觀察與公開資訊（填寫時補來源）

[競品卡B]
競品名稱: 越南社群代購/非正式團購
類型: substitute
目標客群: 價格敏感社群成員
價格區間_twd: 低至中
優勢: 社群信任高、溝通無門檻
劣勢: 品質與供貨穩定性不一、售後與合規風險高
我方差異化: 合規可追溯、穩定供應、實體服務支持
進入障礙: 價格競爭與既有習慣轉換成本
source_note: 社群訪談（填寫時補樣本數）

[競品卡C]
競品名稱: 一般電商平台賣家
類型: indirect
目標客群: 線上比價族群
價格區間_twd: 低至高
優勢: 商品多、比價方便
劣勢: 即時諮詢與線下信任弱，回購關係薄弱
我方差異化: 線下據點+私域關係，提升回購與留存
進入障礙: 需持續控制CAC與履約效率
source_note: 平台公開頁面（填寫時補來源）
```
