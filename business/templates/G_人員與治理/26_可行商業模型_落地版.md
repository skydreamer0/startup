# 26_可行商業模型_落地版

## 用途
把「一般市場常見商業模型」轉成你目前情境可落地的版本，提供 6 個月可執行的營收與毛利策略。

## 適用時機
- 已完成 01-05 基礎戰略後。
- 需要把想法轉成可執行營運模型時。
- 準備進入每月戰情會與獎金結算（22/25）前。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| model_id | string | 是 | 商業模型代碼（例：BM-HYBRID-01） |
| revenue_mix_pct | text | 是 | 各收入來源占比（合計 100%） |
| target_gross_margin_pct | number | 是 | 整體毛利率目標 |
| ccc_target_days | number | 是 | 現金轉換週期目標天數 |
| payback_target_months | number | 是 | CAC 回收期目標（月） |
| core_offer | text | 是 | 主力商品/服務組合 |
| expansion_offer | text | 是 | 第二收入來源設計 |
| kill_rule | text | 是 | 未達標時的停損或調整規則 |

## 填寫規則
1. 先比較「常見模型」，再選 1 個主模型 + 1 個備援模型，不可同時做 3 種以上主軸。
2. 必須同時綁定毛利與 CCC：`target_gross_margin_pct >= 30` 且 `ccc_target_days <= 30`。
3. 收入占比需與 `05`、`12`、`13` 一致；若差異 > 10%，需更新假設說明。
4. 任何促銷方案都要提供「毛利不跌破下限」與「回款週期不拉長」兩項守門條件。

## 輸出範例格式
```text
[模型卡]
model_id: BM-HYBRID-01
主模型: 單次交易 + 會員分層 + B2B團購
備援模型: 單次交易 + 檔期合作費

[收入結構]
商品零售: <xx>%
服務/加值: <xx>%
B2B團購: <xx>%
通路合作: <xx>%

[目標]
target_gross_margin_pct: <數字>
ccc_target_days: <數字>
payback_target_months: <數字>

[停損規則]
若連續2個月未達毛利與CCC雙門檻，啟動備援模型並下修成本。
```

## 常見錯誤
- 一開始就做太多收入線，導致執行分散。
- 只看營收成長，不看毛利與現金回收速度。
- 沒有設定「停損切換」規則，造成現金壓力累積。

---

## 一般人常見的 5 種商業模型（實業/零售場景）
1. **單次交易模型（Transaction）**：主打高周轉與即時現金流，早期最常見。
2. **會員分層模型（Membership）**：用月費/年費換折扣與服務，提升回購可預測性。
3. **組合包模型（Bundle）**：提高客單價與毛利結構，降低單品促銷壓力。
4. **B2B 團購模型（Wholesale/Group Buy）**：單次大量訂單，降低 CAC。
5. **通路合作模型（Channel/Media Fee）**：品牌檔期、上架費、聯名活動分潤。

## 本案建議：可行混合模型（先簡後擴）
### 模型代號
`BM-HYBRID-01`

### 核心設計
- **主軸（前 6 個月）**：單次交易 + 組合包（維持周轉與毛利）。
- **強化（第 2 季）**：輕會員（非吃到飽，採「回購券」型）。
- **第二收入（達標後）**：B2B 團購 + 檔期合作費。

### 收入占比目標（6 個月）
- 商品零售：65%
- 組合包與加值服務：20%
- B2B 團購：10%
- 通路/品牌合作：5%

### 單位經濟門檻
- 整體毛利率：`>= 30%`
- CAC 回收期：`<= 2.5 個月`
- 回購率（60 天）：`>= 30%`
- CCC：`<= 30 天`

## 定價與促銷守門（一般做法 + 你可直接用）
1. **三層毛利護欄**
   - 引流品：22-27%
   - 核心品：32-38%
   - 高毛利附加品：>=45%
2. **促銷上線條件**
   - 促銷後整體毛利率不可低於 30%。
   - 促銷後 CCC 不可高於 30 天。
3. **活動停損條件**
   - 活動後 2 週，若轉換率未提升 15% 且毛利下降 > 3%，立即下架。

## 90 天落地路線（商業模型）
### Day 1-30：模型定錨
- 完成 Top 30 SKU 毛利分層與定價重整。
- 設計 2 組組合包（高頻/家庭照護）。
- 在 11/13 對齊毛利與 CCC 指標欄位。

### Day 31-60：實驗驗證
- 每週 1 次促銷 AB 測試（價格/文案/組合）。
- 啟動 3 家 B2B 試點團購（宿舍/工廠/社群據點）。
- 追蹤 CAC、回購率、訂單毛利貢獻。

### Day 61-90：保留與擴張
- 僅保留達標方案（雙門檻 + 回收期）。
- 對達標商品導入固定補貨節奏，壓低 DIO。
- 產出下一季擴張清單（產品/通路/合作夥伴）。

```text
[模型卡]

備援模型: Transaction + B2B Group Buy

[收入結構]
商品零售: 65
組合包與加值服務: 20
B2B團購: 10
通路合作: 5

[關鍵目標]
target_gross_margin_pct: 31
ccc_target_days: 24
payback_target_months: 2.3
core_offer: 高頻保健補給包 + 家庭照護包
expansion_offer: 宿舍團購月補給方案 + 品牌檔期合作
kill_rule: 連續2個月雙門檻未達標，停做低毛利促銷並切回備援模型
```
