# 10_KOL與社群營運模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Ops Lead |
| Update Frequency | 每週一次；重大活動前後加更 |
| Input From | A_戰略層定位、H_實戰工具紀錄、店務數據 |
| Output To | D_財務模型、F_執行驗證計畫、G_治理會議 |


## 用途
建立員工/KOL 內容與社群運營節奏，將觸及轉換為首購與回購。

## 適用時機
- 社群啟動前。
- 內容成效低於目標時。
- 擴大合作 KOL 前。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| KOL/人員 ID | string | 是 | 內容輸出責任人 |
| 內容主題 | string | 是 | 教育/商品/案例/活動 |
| 發佈頻率 | string | 是 | 例如每週 2 則 |
| 發佈通路 | string | 是 | 社群平台與 LINE |
| 觸及數 | number | 是 | 每期觸及 |
| 互動率_pct | number | 是 | 互動表現 |
| 引流數 | number | 是 | 導入店面或 LINE |
| 成交數 | number | 是 | 可歸因訂單 |

## 填寫規則
1. 每位 KOL 每週至少 1 次可歸因內容。
2. 每月檢討內容題材與成交關聯。
3. 不可使用不實醫療宣稱，需合規審核。
4. 成效統計口徑對齊 `ChannelKPIRecordV1`。

## 輸出範例格式
```text
[KOL成效卡]
creator_id: <ID>
內容主題: <主題>
發佈頻率: <頻率>
發佈通路: <通路>
觸及數: <數字>
互動率_pct: <數字>
引流數: <數字>
成交數: <數字>
備註: <內容>
```

## 常見錯誤
- 只追求觸及，不追可歸因成交。
- 內容節奏不固定，無法累積信任。
- 合規審核缺失導致風險。

### 初版內容支柱（示例）
1. 教育內容：正確選品與使用注意事項（需合規審核）。
2. 信任內容：實體店流程、服務者介紹、真實案例（去識別化）。
3. 促銷內容：限時組合包與回購提醒。
4. 社群內容：節慶活動、互動問答、線下聚點合作。

### 初版合作規範（示例）
- 宣稱邊界：禁用療效保證與誇大用語（需藥師/法顧確認）。
- 審稿流程：草稿 -> 合規審核 -> 發布排程 -> 成效追蹤。
- 上架時程：每週固定二/四上架，重大檔期另行審批。
- 成效結算週期：每月一次，依可歸因成交結算。
