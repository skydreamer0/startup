# 14_募資資料模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder / BD Lead |
| Update Frequency | 雙週更新；對外送件前完整校稿 |
| Input From | A~D 最新版本、F_驗證結果、G_治理紀錄 |
| Output To | 投資人、補助單位、合作方、審查單位 |


## 用途
整理投資人審閱需要的核心敘事與數據欄位，形成可快速閱讀的募資資料骨架。

## 適用時機
- 啟動天使/種子輪募資前。
- 與潛在投資人初談前。
- 每次募資節點更新時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 投資命題一句話 | string | 是 | 清楚說明投資理由 |
| 問題與機會 | text | 是 | 問題規模與市場機會 |
| 解法與差異化 | text | 是 | 為何你能贏 |
| 團隊介紹 | text | 是 | 核心團隊背景與分工 |
| 牽引數據 | list | 是 | 營收、回購、毛利等 |
| 財務重點 | text | 是 | 3 年路徑與關鍵假設 |
| 本輪募資金額_twd | number | 是 | 本輪需求 |
| 資金用途比例 | list | 是 | 產品/營運/市場/合規 |
| 里程碑承諾 | list | 是 | 用資金換到的結果 |
| 主要風險與對策 | text | 是 | 風險透明化 |

## 填寫規則
1. 投資命題不超過 30 字，避免空泛。
2. 牽引數據僅使用可追溯指標。
3. 資金用途需與 `13` 的資金缺口一致。
4. 里程碑需可在 12-18 個月內驗證。
5. 團隊介紹需包含：角色、關鍵經歷、為何適合這題目。

## 輸出範例格式
```text
[募資摘要]
投資命題一句話: <內容>
本輪募資金額_twd: <數字>
跑道(月): <數字>

[團隊]
- 創辦人: <姓名> | <角色> | <關鍵經歷>
- 合作藥師: <姓名> | <執照/資格> | <相關經驗>
- 顧問: <姓名> | <專業領域> | <如何協助>

[資金用途]
- 供應鏈與庫存: <比例>
- 通路與社群: <比例>
- 團隊與營運: <比例>
- 合規與法務: <比例>

[里程碑]
M1: <里程碑>
M2: <里程碑>
M3: <里程碑>
```

## 常見錯誤
- 敘事很完整但數據無法驗證。
- 缺少團隊介紹，投資人無法判斷執行力。
- 資金用途與里程碑不對應。
- 風險只寫優化，不寫最壞情境。

## 投資人 10 分鐘審閱模板
1. 問題是否真實且高頻？
2. 解法是否有驗證證據？
3. 單位經濟是否可持續？
4. 團隊與合規是否可執行？
5. 本輪資金是否對應明確里程碑？

## 初版填寫示例（可直接改）
```text
[募資摘要]
投資命題一句話: 在下新莊建立越南族群導向的合規健康補給與社群通路引擎
本輪募資金額_twd: 3000000
跑道(月): 18

[團隊]
- 創辦人: <姓名> | 營運與商業開發 | 具備藥局通路合作經驗
- 合作藥師: <姓名> | 藥師執照 | 合規把關與處方諮詢（需確認合作模式）
- 社群顧問: <姓名> | 越南族群社群經營 | 協助KOL合作與內容策略

[問題與機會]
- 越南族群對可信且語言友善的商品/服務存在高頻需求
- 既有通路多為泛大眾設計，缺乏深度社群關係與私域回購

[牽引數據]
- 90天目標有效顧客: 50-100
- 30日回購率目標: >= 25%
- 月毛利率目標: >= 28%
- CAC_twd 目標: <= 180

[資金用途]
- 供應鏈與庫存: 35%
- 通路與社群: 25%
- 團隊與營運: 25%
- 合規與法務: 10%
- 預備金: 5%

[里程碑]
M1-M3: 完成試點與可重複首購漏斗
M4-M6: 建立回購機制並接近損平
M7-M12: 啟動第二收入引擎（B2B/KOL共銷）
M13-M18: 準備複製第二據點條件
```

### 初版投資人Q&A準備（示例）
1. 為何是下新莊起步，不是全台？
2. 法規邊界如何控管（需藥師/法顧確認）？
3. 團隊目前幾人？誰負責哪些關鍵角色？
4. 第二收入來源的啟動條件與可驗證數據是什麼？
5. 若 CAC 持續上升，停損策略為何？
6. 藥師合作模式是全職還是顧問？合作穩定性如何？
