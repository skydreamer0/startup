# 30_報價與合約簡版模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Ops / BD |
| Update Frequency | 每次訪談或報價後即時更新 |
| Input From | 現場訪談、客訴回饋、合作洽談紀錄 |
| Output To | A_客群洞察、C_營運策略、E_對外資料 |


## 用途
提供 B2B 團購、KOL 合作、通路合作等商業往來的報價單與簡版合約格式，確保每筆交易有清楚的範圍、價格與責任定義。

## 適用時機
- B2B 團購（宿舍/工廠/社群據點）提案時。
- KOL 合作洽談時。
- 品牌聯名或檔期合作時。
- 任何金額 > TWD 10,000 的商業合作。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| quote_id | string | 是 | 報價單編號（例：QT-2026-001） |
| date | date | 是 | 報價日期 |
| client_name | string | 是 | 客戶/合作方名稱 |
| cooperation_type | string | 是 | 團購/KOL/通路合作/其他 |
| items | list | 是 | 品項、數量、單價、小計 |
| total_amount_twd | number | 是 | 總金額 |
| payment_terms | text | 是 | 付款條件 |
| delivery_terms | text | 是 | 交付方式與時程 |
| validity_days | number | 是 | 報價有效天數 |

## 填寫規則
1. 報價有效期不超過 14 天。
2. B2B 團購需明確 MOQ（最低訂購量）。
3. 付款條件預設收取 50% 訂金。
4. 所有合約需加註合規聲明（不含處方藥品直接銷售）。

## 常見錯誤
- 口頭議價沒有留下書面紀錄，事後認知不一致。
- 沒有明確的 MOQ 或 MOV（最低訂單金額），變成什麼都能訂。
- KOL 合作沒有追蹤機制，花了錢不知道效果。
- 合規聲明缺失，合作方宣稱療效造成法律風險。
