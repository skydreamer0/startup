# 29_客戶訪談紀錄模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Ops / BD |
| Update Frequency | 每次訪談或報價後即時更新 |
| Input From | 現場訪談、客訴回饋、合作洽談紀錄 |
| Output To | A_客群洞察、C_營運策略、E_對外資料 |


## 用途
提供標準化的訪談紀錄格式，確保每次訪談都有結構化輸出，可供後續分析、團隊共享與投資人佐證使用。

## 適用時機
- 創業前期的需求訪談（`27` 第1週）。
- 新品類/新通路上線前的驗證。
- 流失顧客訪談。
- 定期顧客回饋蒐集。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| interview_id | string | 是 | 唯一編號（例：INT-2026-001） |
| date | date | 是 | 訪談日期 YYYY-MM-DD |
| interviewer | string | 是 | 訪談者姓名 |
| interviewee_profile | text | 是 | 受訪者背景（不記錄個資） |
| channel | string | 是 | 訪談管道（面對面/電話/LINE） |
| duration_min | number | 是 | 訪談時長（分鐘） |
| key_findings | list | 是 | 3-5 項關鍵發現 |
| pain_points | list | 是 | 受訪者提到的痛點 |
| willingness_to_pay | text | 否 | 願付價格或價值感受 |
| next_action | text | 是 | 後續動作（邀請試用/追蹤/放棄） |

## 填寫規則
1. 每場訪談控制在 15-25 分鐘。
2. 不記錄個人身分資訊（姓名、電話等），只記錄可分析的特徵。
3. 關鍵發現用受訪者原話 + 你的解讀兩欄並列。
4. 每次訪談結束後 24 小時內完成紀錄。

---

## 訪談問題清單（越南族群健康補給場景）

### A. 現況行為（了解他們怎麼做）
1. 你平常在哪裡買保健品/日用品？為什麼選那邊？
2. 最常買的前 5 樣東西是什麼？大概多久買一次？
3. 你會透過什麼管道知道有新商品？（朋友/社群/廣告/實體店）

### B. 痛點挖掘（了解他們的困擾）
4. 有沒有買到不對的東西或買不到想要的東西的經驗？怎麼處理的？
5. 用中文看說明書/問藥師會不會有困難？哪些情況最卡？
6. 對目前買東西的地方，最不滿意的是什麼？

### C. 需求驗證（了解他們要什麼）
7. 如果有一家越語服務的藥局／健康商店，你最希望它賣什麼？
8. 你會因為什麼原因願意換一家店買？
9. 如果可以在 LINE 上收到健康提醒和商品推薦，你會想用嗎？

### D. 付費意願（了解價值感受）
10. 你現在每個月花多少在保健品/日用品上？
11. 如果有更方便可靠的管道，你願意多付一點嗎？大概多少？
12. 你會推薦朋友來嗎？什麼情況下會推薦？

## 常見錯誤
- 訪談時引導受訪者回答你想聽的答案。
- 只記錄支持你假設的回答，忽略否定訊號。
- 訪談後沒有即時紀錄，隔天才回憶導致失真。
- 訪談太長（>30 分鐘），受訪者疲勞後回答品質下降。
