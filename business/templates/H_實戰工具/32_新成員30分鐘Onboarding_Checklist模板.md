# 32_新成員30分鐘Onboarding_Checklist模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Ops / HR Ops |
| Update Frequency | 每次新人報到時更新 |
| Input From | ROLE_GUIDE、20_主資料字典、25_戰情會制度 |
| Output To | 新人首週任務單、角色責任邊界、協作節奏 |

## 用途
用 30 分鐘完成新人最小可用 onboarding，確保新加入成員知道「要看什麼、誰負責什麼、這週先做什麼」。

## 適用時機
- 新人第一天。
- 角色異動或跨部門支援開始前。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 新成員姓名 | string | 是 |  |
| 角色 | enum | 是 | Founder/Ops/Finance/BD/其他 |
| Onboarding 日期 | date | 是 | YYYY-MM-DD |
| Buddy | string | 是 | 主要協作窗口 |
| 首週目標 | list | 是 | 1~3 件可驗收任務 |
| 必讀文件清單 | list | 是 | 依角色填入 3~5 份 |
| 系統權限狀態 | list | 是 | Notion/雲端硬碟/群組/報表 |

## 30 分鐘流程
1. **5 分鐘**：公司現況與本月核心目標。
2. **10 分鐘**：角色責任邊界與 KPI 定義（對齊 `20`）。
3. **10 分鐘**：必讀文件導覽（依 `ROLE_GUIDE.md`）。
4. **5 分鐘**：首週任務與回報節奏確認。
