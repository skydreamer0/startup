# 16_90天驗證計畫模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder + Ops |
| Update Frequency | 每週更新；里程碑週（W4/W8/W12）重審 |
| Input From | A~D 假設與指標、H_客戶互動記錄 |
| Output To | G_戰情會決策、E_對外敘事與送件 |


## 用途
定義核心商業假設與驗證門檻，透過 Gate Review 機制快速判斷是否達到早期 Product-Market Fit 訊號。

> **定位說明**：本文件聚焦「假設管理與決策機制」。具體的每週任務請參考 `27_30天創業落地執行版_非模板.md`（前 30 天）和 `28_創業落地Roadmap_12週.md`（12 週完整路線圖）。

## 適用時機
- 試點啟動前，定義要驗證什麼。
- 新客群/新通路上線前。
- 需要快速停損或轉向時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 假設 ID | string | 是 | 每個假設唯一編號 |
| 假設內容 | text | 是 | 可驗證敘述 |
| 驗證方法 | text | 是 | 訪談、A/B、實購 |
| 成功門檻 | string | 是 | 數字門檻 |
| 失敗門檻 | string | 是 | 停損條件 |
| 責任人 | string | 是 | owner |
| Gate 週次 | string | 是 | 在哪個 Gate 檢視 |
| Gate 決策 | string | 是 | go/pivot/stop |

## 填寫規則
1. 每個假設必須可用數字驗證，不可只寫「改善」。
2. 成功門檻和失敗門檻之間要有「灰色地帶」的處理方式。
3. Gate Review 固定在 W4/W8/W12 執行，不可跳過。
4. 若觸發失敗門檻，需在 7 天內提出調整方案或停損決策。

## 輸出範例格式
```text
[假設卡]
假設ID: HYP-001
假設內容: <內容>
驗證方法: <內容>
成功門檻: <數字>
失敗門檻: <數字>
責任人: <角色>
Gate週次: W4

Gate決策: <go/pivot/stop>
```

## 常見錯誤
- 假設太模糊，無法用數字驗證。
- 只設成功門檻，沒有失敗門檻，導致永遠「再試試」。
- Gate 會議沒有產出決策，變成進度報告。
- 假設與實際執行任務脫節。

## Gate Review 流程

### Gate 會議模板
```text
[Gate Review]
Gate 週次: W4 / W8 / W12
日期: 2026-__-__
參與者: ________

[假設檢視]
| 假設ID | 成功門檻 | 實際結果 | 判定 |
|--------|---------|---------|------|
| HYP-001 |        |         | ✅/⚠️/❌ |
| HYP-002 |        |         | ✅/⚠️/❌ |
| HYP-003 |        |         | ✅/⚠️/❌ |

[整體決策]
- ✅ Go：所有核心假設達標 → 進入下一階段
- ⚠️ Pivot：部分達標 → 調整方案，7天內產出新計畫
- ❌ Stop：核心假設失敗 → 停損或轉向

[決策]: ________
[行動計畫]: 
1. ________
2. ________
3. ________

[下次 Gate]: W___
```

## 初版假設卡（越南健康補給站場景）

### HYP-001：首購可行性
```text
假設ID: HYP-001
假設內容: 下新莊越南族群可在「實體店+LINE」模式下形成穩定首購
驗證方法: 到店導流、LINE 追蹤、首購紀錄
成功門檻: 90天首購 >= 50位
失敗門檻: 90天首購 < 30位
灰色地帶: 30-49位 → 分析漏斗斷點，延長驗證4週
責任人: 通路負責人
Gate週次: W4（初判）、W12（最終）
```

### HYP-002：回購黏著度
```text
假設ID: HYP-002
假設內容: 首購後30天回購率可達25%以上
驗證方法: 分層回購腳本（7/14/30天）+ LINE 數據追蹤
成功門檻: 30日回購率 >= 25%
失敗門檻: 30日回購率 < 15%
灰色地帶: 15-24% → 重新調整觸達頻率與商品推薦
責任人: CRM 負責人
Gate週次: W8
```

### HYP-003：毛利可持續性
```text
假設ID: HYP-003
假設內容: 商品主收入可維持月毛利率 >= 28%
驗證方法: SKU 毛利追蹤與促銷對照
成功門檻: 月毛利率 >= 28%
失敗門檻: 連續2月 < 20%
灰色地帶: 20-27% → 調整引流品/核心品比例
責任人: 採購負責人
Gate週次: W12
```

### HYP-004：B2B 收入補充
```text
假設ID: HYP-004
假設內容: B2B 團購可在 W8 前貢獻 >= 10% 營收
驗證方法: 宿舍/工廠團購試單
成功門檻: B2B 占營收 >= 10%
失敗門檻: W8 時 B2B 營收 = 0
灰色地帶: 1-9% → 調整 MOQ 或品項組合
責任人: 業務負責人
Gate週次: W8
```

## 初版 Gate 規則

1. **W4 Gate**：首購不足門檻 → 縮減通路聚焦高轉換點；達標 → 啟動回購機制。
2. **W8 Gate**：回購不足門檻 → 重做商品組合與觸達節奏；達標 → 擴大客群與啟動 B2B。
3. **W12 Gate**：毛利與回購雙達標 → 進入第2階段擴張準備；未達標 → 評估是否 pivot 品類或調整定位。
