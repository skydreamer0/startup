# 18_風險登錄與應對模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder + Ops |
| Update Frequency | 每週更新；里程碑週（W4/W8/W12）重審 |
| Input From | A~D 假設與指標、H_客戶互動記錄 |
| Output To | G_戰情會決策、E_對外敘事與送件 |


## 用途
建立風險登錄簿，追蹤法規、供應、聲譽、財務、人力等風險的機率、衝擊與處置進度。

## 適用時機
- 專案啟動即建立。
- 每週/月例會更新。
- 發生重大事件後立即更新。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 風險 ID | string | 是 | 唯一編號 |
| 風險類型 | enum | 是 | regulation/supply/reputation/finance/people |
| 風險描述 | text | 是 | 具體事件敘述 |
| 發生機率 | number | 是 | 1-5 |
| 影響程度 | number | 是 | 1-5 |
| 風險等級 | enum | 是 | low/medium/high/critical |
| 觸發訊號 | text | 是 | 何時判定風險啟動 |
| 應對方案 | text | 是 | 預防/應變 |
| 責任人 | string | 是 | owner |
| 截止日 | date | 是 | 改善時程 |

## 填寫規則
1. 風險等級依機率與影響矩陣計算。
2. high/critical 需定義 24-72 小時內動作。
3. 每項風險需有可觀測觸發訊號。
4. 合規風險需標記 `需藥師/法顧確認`。

## 輸出範例格式
```text
[風險卡]
risk_id: RSK-001
風險類型: regulation
風險描述: <內容>
發生機率: <1-5>
影響程度: <1-5>
風險等級: <low/medium/high/critical>
觸發訊號: <內容>
應對方案: <內容>
責任人: <角色>
截止日: YYYY-MM-DD
需藥師/法顧確認: true
```

## 常見錯誤
- 只列風險不列觸發訊號。
- high 風險沒有具體時限。
- 未定期更新，風險清單失真。

## 風險矩陣模板
| 機率\影響 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| 1 | low | low | low | medium | medium |
| 2 | low | low | medium | medium | high |
| 3 | low | medium | medium | high | high |
| 4 | medium | medium | high | high | critical |
| 5 | medium | high | high | critical | critical |
