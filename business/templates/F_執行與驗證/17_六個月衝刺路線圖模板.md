# 17_六個月衝刺路線圖模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder + Ops |
| Update Frequency | 每週更新；里程碑週（W4/W8/W12）重審 |
| Input From | A~D 假設與指標、H_客戶互動記錄 |
| Output To | G_戰情會決策、E_對外敘事與送件 |


## 用途
把 6 個月衝刺目標轉成月度里程碑、跨部門依賴與資源配置，對齊整體執行節奏。

## 適用時機
- 季度與半年度規劃。
- 每月例會回顧。
- 里程碑或預算重排時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 月份 `period` | string | 是 | `YYYY-MM` |
| 月目標 | text | 是 | 當月主要成果 |
| 里程碑 | list | 是 | 可驗收項目 |
| 依賴項 | list | 是 | 合規、供應、人力、通路 |
| 資源需求_twd | number | 是 | 當月資源預估 |
| 風險提示 | text | 是 | 主要執行風險 |
| owner | string | 是 | 負責角色 |

## 填寫規則
1. 每月最多 3 個核心里程碑。
2. 里程碑需可驗收（文件、數字、交付物）。
3. 每月列出「不做事項」避免分散。
4. 與 `13` 財務資金節點一致。

## 輸出範例格式
```text
[月度卡]
period: YYYY-MM
月目標: <內容>
里程碑:
- M1: <內容>
- M2: <內容>
- M3: <內容>
依賴項: <內容>
資源需求_twd: <數字>
風險提示: <內容>
owner: <角色>
```

## 常見錯誤
- 里程碑太多，無法聚焦。
- 沒列依賴項，導致執行卡住。
- 路線圖與預算脫節。
