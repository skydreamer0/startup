# 24_資金流轉與現金循環管理模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Finance Lead |
| Update Frequency | 每週更新追蹤；每月結帳後版本凍結 |
| Input From | C_營運層KPI、採購成本、銷售報表 |
| Output To | E_募資/補助文件、G_績效結算、Founder決策 |


## 用途
建立資金流轉管理機制，以 CCC 為核心，連動庫存、應收與應付策略，達成 `ccc_days <= 30`。

## 適用時機
- 每週現金會議。
- 月結與資金規劃。
- 出現現金壓力或庫存積壓時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `period` | string | 是 | `YYYY-MM` |
| `dio_days` | number | 是 | 庫存週轉天數 |
| `dso_days` | number | 是 | 應收帳款天數 |
| `dpo_days` | number | 是 | 應付帳款天數 |
| `ccc_days` | number | 是 | `dio_days + dso_days - dpo_days` |
| `cash_alert_flag` | boolean | 是 | 是否觸發資金預警 |
| 13週現金最低點_twd | number | 是 | 現金預估最低點 |
| 高風險客戶帳期政策 | text | 是 | 帳期限制與預收規範 |

## 填寫規則
1. CCC 目標固定 <= 30 天。
2. 子目標：`dio_days <= 24`、`dso_days <= 3`、`dpo_days >= 18`。
3. 每週更新 13 週滾動現金預估，若低於警戒值需開啟預警。
4. 團購/高風險客戶優先採部分預收，降低 `dso_days` 風險。

## 輸出範例格式
```text
[現金循環主檔]
period: 2026-05
dio_days: 22
dso_days: 2
dpo_days: 18
ccc_days: 6
cash_alert_flag: false
13週現金最低點_twd: 145000
高風險客戶帳期政策: 新客不得超過7天帳期；團購需30%預收
```

## 常見錯誤
- 只看現金餘額，不看CCC惡化趨勢。
- 應收帳款管理鬆散導致資金卡住。
- 未做13週滾動預估，資金斷點無預警。

[調整行動]
