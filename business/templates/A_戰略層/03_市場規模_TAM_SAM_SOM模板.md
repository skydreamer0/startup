# 03_市場規模_TAM_SAM_SOM模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder |
| Update Frequency | 每月一次；重大策略調整時即時更新 |
| Input From | 客戶訪談、競品研究、市場數據 |
| Output To | C_營運層、D_財務層、E_對外送件、F_執行與驗證 |


## 用途
建立市場規模估算框架（TAM/SAM/SOM），用於募資與補助的市場可行性說明。

## 適用時機
- 完成初步客群驗證後。
- 募資簡報與補助申請撰寫前。
- 每半年重估一次。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| 市場定義 | text | 是 | TAM/SAM/SOM 各自定義 |
| 估算方法 | string | 是 | Top-down 或 Bottom-up |
| 主要假設 | list | 是 | 至少 3 項 |
| `period` | string | 是 | 一律 `YYYY-MM` |
| 幣別 | string | 是 | 一律 TWD |
| 敏感度區間 | text | 是 | low/base/high 三情境 |
| `source_note` | string | 是 | 數據來源與日期 |

## 填寫規則
1. TAM、SAM、SOM 必須採同一期間與幣別。
2. 每個數字必須可回溯到來源或明確假設。
3. 需同時提供 Base/Low/High 三情境。
4. 若數據來自估計，需標註不確定性等級。

## 輸出範例格式
```text
[TAM]
市場定義: <定義>
估算值_twd: <數字>
方法: <top-down/bottom-up>
source_note: <來源>

[SAM]
市場定義: <定義>
估算值_twd: <數字>

[SOM]
市場定義: <定義>
估算值_twd: <數字>

[敏感度]
low_case_twd: <數字>
base_case_twd: <數字>
high_case_twd: <數字>
```

## 常見錯誤
- TAM 很大但與當前地區/客群無關。
- SAM 與 SOM 缺乏通路能力約束。
- 沒有提供來源，僅引用二手轉載。

## 初版填寫示例（可直接改）
```text
[期間與口徑]
period: 2026-02
currency: TWD
方法: Bottom-up為主，Top-down交叉驗證
source_note: 政府公開統計、地方人口資料、訪談與試點假設（填寫時補正式來源連結）

[TAM]
市場定義: 台灣越南族群相關健康/生活商品與藥局通路可服務需求總量
估算值_twd: 2000000000
方法: Top-down

[SAM]
市場定義: 北部都會可觸達越南族群之商品與服務需求
估算值_twd: 350000000
方法: Top-down + 地區縮限

[SOM]
市場定義: 下新莊單點在6-12個月可實際取得之交易規模
估算值_twd: 9000000
方法: Bottom-up

[Bottom-up假設]
單店可服務客數: 300
月活躍購買率: 0.35
客單價_twd: 650
月交易筆數估算: 300 * 0.35 = 105
月營收估算_twd: 105 * 650 = 68250
年化營收估算_twd: 819000

[敏感度]
low_case_twd: 5000000
base_case_twd: 9000000
high_case_twd: 14000000
```

### 假設風險標註
- 若月活躍購買率低於25%，需優先調整通路與回購策略。
- 若客單價低於TWD 550，需檢討SKU結構與組合包設計。
- 若法規流程限制服務範圍，需同步下修SOM（需藥師/法顧確認）。
