# 01_創業論點與願景模板

## Metadata
| 欄位 | 內容 |
| --- | --- |
| Owner | Founder |
| Update Frequency | 每月一次；重大策略調整時即時更新 |
| Input From | 客戶訪談、競品研究、市場數據 |
| Output To | C_營運層、D_財務層、E_對外送件、F_執行與驗證 |


## 用途
建立創業核心論點，說明要解決的問題、目標客群、方案合理性與長期願景，作為後續市場、營運與募資敘事起點。

## 適用時機
- 專案啟動第 1 週。
- 與團隊、顧問、投資人對齊方向時。
- 每季檢討策略是否偏移時。

## 必填欄位
| 欄位 | 型別 | 必填 | 說明 |
| --- | --- | --- | --- |
| `startup_id` | string | 是 | 對應 `StartupProfileV1.startup_id` |
| `company_name` | string | 是 | 創業主體名稱 |
| `pilot_region` | string | 是 | 例如下新莊 |
| `target_segments` | string[] | 是 | 例如越南族群分層 |
| 核心問題陳述 | text | 是 | 1-2 句清楚描述痛點 |
| 解法假設 | text | 是 | 目前方案與可驗證假設 |
| 為何現在 | text | 是 | 市場窗口、政策或行為變化 |
| 不可替代優勢 | text | 是 | 供應鏈、通路、專業資格等 |
| 6 個月成功定義 | text | 是 | 對應 16/17 文件 KPI |

## 填寫規則
1. 問題陳述需具體到場景、頻率與損失。
2. 解法假設必須可在 90 天內驗證。
3. 不可替代優勢要有可觀測證據，不可只寫主觀描述。
4. 任何法規相關描述加註 `需藥師/法顧確認`。

## 輸出範例格式
```text
[創業論點]
startup_id: STP-YYYY-XXX
company_name: <公司名稱>
pilot_region: <地區>
target_segments: [<客群1>, <客群2>]

核心問題陳述:
- <問題1>
- <問題2>

解法假設:
- 假設A: <內容>
- 驗證方式: <方法>
- 驗證門檻: <數字>

為何現在:
- <市場/政策/供應鏈因素>

不可替代優勢:
- <優勢1 + 證據>
- <優勢2 + 證據>

6個月成功定義:
- <KPI 1>
- <KPI 2>
```

## 常見錯誤
- 把願景寫成口號，沒有可衡量指標。
- 解法假設無法在短期內驗證。
- 忽略地區與客群限制，敘事過大。

## 初版填寫示例（可直接改）
```text
[創業論點]
startup_id: STP-2026-001
company_name: 越友健康補給站（暫名）
pilot_region: 新北市新莊區（下新莊）
target_segments: [越南移工, 越南新住民, 越南家庭照護者]
stage: mvp
budget_range_twd: 100000-300000

核心問題陳述:
- 越南族群在下新莊取得熟悉且可信的健康/生活商品不穩定，且資訊多來自非正式管道，造成決策風險。
- 涉及處方相關需求時，語言與流程理解落差高，導致服務可近性與信任不足（需藥師/法顧確認）。

解法假設:
- 假設A: 以「實體藥局據點 + LINE 私域 + 越語社群」可在90天內建立可重複首購與回購。
- 驗證方式: 首批50-100位有效顧客試點，追蹤首購、30日回購與客訴率。
- 驗證門檻: 90天首購>=50位，30日回購率>=25%，重大客訴=0。

為何現在:
- 越南社群在北部聚落成熟，資訊傳播速度快，社群型商業模式可低成本驗證。
- 實體藥局信任基礎可與數位私域結合，縮短獲客到成交路徑。

不可替代優勢:
- 供應鏈與採購能力：可建立高頻剛需SKU與穩定補貨節奏。
- 執照與專業合作基礎：已有合法藥局/合作藥師框架可承接處方相關服務（需藥師/法顧確認）。
- 社群擴散策略：規劃越南語KOL與社群節點合作，降低獲客成本。

6個月成功定義:
- 月付費顧客>=180
- 月毛利率>=28%
- 月營運現金流接近損平（>= -10%）
```

### 補充：不做事項（前6個月）
- 不同時擴張多城市。
- 不進行未驗證需求的大量囤貨。
- 不做灰色法規邊界服務（需藥師/法顧確認）。
